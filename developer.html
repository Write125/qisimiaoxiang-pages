3. Requested API capabilities

ReportingRead campaign, ad group, ad, and account-level metrics (spend, impressions, clicks, conversions) for dashboards and exports.
Campaign managementCreate and update campaigns, ad groups, and ads in bulk; pause/enable entities; adjust budgets and bids within TikTok policy limits.
OAuthObtain and refresh advertiser access tokens via TikTok for Business authorization; redirect handled at oauth.html.

Not requested

  • Reselling API access to unrelated third parties
  • Content Posting API / posting organic videos to consumer feeds
  • Collecting unrelated TikTok user personal data beyond advertising operations

4. Integration workflow

  1. Authorized staff opens our internal tool or documented authorization URL.
  2. User signs in with TikTok for Business and grants permissions for our developer application.
  3. TikTok redirects to https://app.bayme.store/oauth.html with an authorization code.
  4. Our private server exchanges the code for access_token and refresh_token (tokens are never stored in this static website).
  5. Server calls Marketing API endpoints for reporting and approved management actions on authorized advertiser_id values.
  6. Tokens are refreshed before expiry; access is revoked when staff leave or authorization is removed in TikTok.
