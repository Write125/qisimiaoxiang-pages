5. Authorized advertiser accounts

Our integration operates on advertiser_id values returned after OAuth for accounts where:

  • Bayme owns the advertiser account, or
  • A partner Business Center has added our staff with explicit ad account permissions and the authorized user completes OAuth.

We do not access advertiser accounts without TikTok authorization.

6. Integration workflow

  1. Authorized staff opens TikTok’s advertiser authorization URL for our developer application.
  2. User signs in with TikTok for Business and grants permissions.
  3. TikTok redirects to https://www.bayme.store/oauth.html with an authorization code.
  4. Our private server exchanges the code for tokens (not stored in this static site).
  5. Server calls Marketing API with the appropriate advertiser_id per account.
  6. Tokens are refreshed per TikTok rules; access ends when authorization is revoked.
