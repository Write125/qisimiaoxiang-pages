TikTok Marketing API — how we use it

We are applying for TikTok Marketing API access to build and operate an internal tool for our own ad accounts. The tool is used only by staff who already have permission in TikTok Ads Manager.

Capabilities we request

  • Reporting — Read campaign, ad group, and ad performance metrics for analysis and daily operations.
  • Campaign management — Create and update campaigns, ad groups, and ads in bulk to improve efficiency (same workflows we already perform manually in Ads Manager).
  • OAuth authorization — Staff sign in with TikTok for Business; we store access tokens securely on our servers to call the API on behalf of authorized advertisers.

What we do not do

  • We do not resell API access or operate a multi-tenant SaaS for unrelated companies.
  • We do not use the API to scrape consumer TikTok profiles for unrelated purposes.
  • We do not publish OAuth tokens or advertiser data publicly.

Security & data handling

  • HTTPS only for this site and OAuth redirect endpoints.
  • API credentials and tokens are stored in private server configuration (not in this public website).
  • Access to internal tools is restricted to authorized team members.
  • We follow TikTok’s developer terms and Marketing API policies.
